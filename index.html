Projeto principal

API .NET com DDD, CQRS e autenticação JWT

Backend construído com padrões corporativos: o domínio não aceita estado inválido, a leitura é separada da escrita e a segurança é tratada desde o desenho. Sobe inteiro com docker compose up.

  • Domínio protegido: Value Objects imutáveis e invariantes com exceções customizadas.
  • CQRS: consultas projetadas direto no DbContext, sem carregar agregados à toa.
  • Segurança: JWT com claims customizadas e hashing de senha com PBKDF2.
  • Qualidade: validação em duas camadas (API e domínio) e testes automatizados.

Decisões de arquitetura

DecisãoPor quêTrade-off
Value Objects imutáveisUm valor inválido nunca chega a existirMais classes
Invariantes no domínioRegra de negócio não depende da APITratar exceções na borda
CQRS com projeçõesLeituras rápidas e simplesDois modelos mentais
JWT + claimsAutorização por perfilGestão de expiração
PBKDF2Hash lento, com salt, resistente a força brutaCusto de CPU
